# Checklist de entrega

Marca cada punto antes de publicar el repositorio.

## 1. Registro en developer.arm.com

- [ ] Cuenta creada.
- [ ] Correo verificado.
- [ ] MFA activado.
- [ ] Acceso a AVH por SSO comprobado.
- [ ] Captura `evidencias/01-cuenta-arm.png`.
- [ ] Captura `evidencias/01b-acceso-avh.png`.

## 2. Demo de Corellium

- [ ] Trial localizado en el panel.
- [ ] Días restantes y core-hours documentados.
- [ ] Captura `evidencias/02-demo-corellium.png`.
- [ ] Captura `evidencias/02b-dispositivo.png`.
- [ ] Instancia apagada al terminar.

## 3. Raspberry Pi virtual

- [ ] Dispositivo Raspberry Pi 5 creado.
- [ ] Firmware Raspberry Pi OS Desktop 11.2.0.
- [ ] Consola accesible.
- [ ] `uname -m` = `aarch64`.
- [ ] `nproc` = 4.
- [ ] Memoria y disco verificados.
- [ ] Red verificada.
- [ ] Capturas `03-*`.

## 4. GIST del docente

- [ ] Repositorios de Debian 11 corregidos.
- [ ] Dependencias instaladas.
- [ ] asdf v0.14.1 instalado.
- [ ] Plugin erlang agregado.
- [ ] OTP 27.3.4.19 compilado.
- [ ] `emu_flavor` verificado.
- [ ] rebar3 instalado.
- [ ] `hello_erlang` creado y compilado.
- [ ] Crypto AES verificado.
- [ ] Capturas `04-*` y log.

## 5. OpenCode

- [ ] Captura de la sesión.
- [ ] Ejemplo de error resuelto.

## 6. Evidencias

- [ ] Nombres según la tabla.
- [ ] Salidas de texto en `evidencias/texto/`.

- [ ] Datos sensibles ocultos.

- [ ] 404 de apt documentado.

## 9. Documentación final
