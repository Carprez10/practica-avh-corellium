# Evidencias

Aquí van las capturas, salidas de texto y logs de la práctica.

## Reglas

1. Usar los nombres exactos de la tabla de
   [`docs/06-evidencias.md`](../docs/06-evidencias.md).
2. No publicar correos completos, tokens, cookies, contraseñas ni llaves
   privadas.
3. Las capturas deben incluir el comando ejecutado y el prompt
   `pi@raspberrypi` cuando sea posible.
4. Las salidas largas van en `texto/` o `logs/`, no en una sola captura
   ilegible.

## Estructura

```text
evidencias/
├── 01-cuenta-arm.png
├── 02-demo-corellium.png
├── 03f-free-swap.png
├── 03g-swap.png
├── 04d-jit.png
├── ...
├── logs/
│   └── aplicar_gist.log
└── texto/
    ├── 03-uname.txt
    ├── 04-crypto.txt
    └── ...
```
